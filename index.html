How much yarn do I need for a blanket or scarf?

The amount of yarn a project takes depends on three things: the size of the finished piece, how thick the yarn is, and how dense the stitch pattern is. A cabled blanket in bulky yarn uses far more yardage than a plain stockinette scarf of the same size, because texture and thickness both add to how much yarn gets packed into each square inch.

This calculator uses typical yardage-per-square-inch figures for each standard yarn weight category, then adjusts for stitch pattern and adds a small safety buffer — so you're not caught short mid-project.

What if I already have yarn and don't know what to make?

Switch to "I have yarn" mode above, enter your total yardage and the width you'd like to work at, and the calculator works backwards to tell you the maximum length you can make — handy for using up leftover skeins or stash yarn without guessing.
